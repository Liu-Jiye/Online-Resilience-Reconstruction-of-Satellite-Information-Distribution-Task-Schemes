# P5 用户确认事项

以下确认来自本次对话。仅登记批准范围，不改写历史实验记录。

1. **仅执行P5**：完成后分析整理、形成阶段报告，直接提交并推送GitHub；不自动启动P6。重要方案决策与用户交互。
2. **规则主线**：用户选择“采用规则主线，ET/A6不适用”。A5比较固定、只调B、只调w、联合规则；A10比较规则控制有/无剩余时间特征。未开展新的ET训练或A6重训。
3. **共享50ms升级触发**：紧急未服务或效用恢复比不足时触发；恢复比阈值仅在事前固定的验证子集与候选{0.95,1.0}内选择。用户选择“采用这两项处理”。候选评分与最终阈值封存于upgrade_threshold.json。
4. **IPC范围**：在缺少完整时序PDDL规划/验证适配器的情况下，按原方案§4.7完成固定来源、结构解析、去重/同源和适用性审计，明确未开展IPC性能实验，不用扁平化ISL替代。此项与上一项一并获用户确认。

P5全部普通实现和验证均在上述范围内推进。配对子集、计时、失败计分和适用性细节见P5_EXECUTION_V1.md及阶段报告；未把不适用项标为实验已完成。
