# P3 正式计时实现冻结 v1

用户已确认采用等价加速版本。正式标签和验证使用 `0.3.3-p3-indexed-v2`，不再根据验证表现修改实现。原v2、预检v0.3.0/0.3.1/0.3.2的诊断记录保留。

变更仅为等价的完整基线批量检查、在线资源索引、目标函数增量计算及为完整最终校验预留时间。无物理约束、资格v2、原索引邻域、单项替换/插入、累计B、目标词典序变更。不能保证按时完成的情况仍按失败记分。

独立完整校验器新增索引实现，由原validation.py作可审计文本变换得到；它只导入模型及dataclasses，不导入或调用搜索、placement或搜索索引。每次完整校验自建接触/日历索引，完整检查任务、双方资源、日历、冻结、邻域、预算与全部轨迹。响应内最终校验不使用搜索给出的可行标签；响应外另由原validation.py逐条回放已验证输出，不能用离线回放挽救超时结果。变换记录包含源和结果哈希。

截止调度：一次完整当前状态校验探测也计入响应；搜索至少预留其2倍时间，接受更长轨迹前按轨迹长度放大预留。此为计时调度，不扩大50ms总预算。所有越界如实归零。

验收证据：40项初始等价/边界测试、400组异常计划校验器全部字段对照、72个实际训练情景（D1/D2-S/D2-O×双负载×12情景）非截止回放，计划、轨迹、强制删除、资格与指标均一致。最后训练计时：默认0/36超时，中竞争11/36超时。没有以“必须零超时”筛样或放宽截止；负载/参数大时的剩余失败正是本轮需要保留的证据。主完整回归另存 runtime_regression_final.xml。

P3输入已全部生成：4000训练、1000验证、每场景两负载；参考计划10000份均与独立位集贪心完全一致。独立输入复核复现120000个事件、核验32星组与划分，测试场景0、修复调用0。

规则阈值候选和宏平均排序沿用p3_v1.json，完整验证一次选择，不新增候选。ET训练仅默认层4000基实例、每例预定一个情景×20动作，最多80000条。训练/网格的状态提取在离线标注侧单列成本，不计入固定方法不需要的特征时间；在线规则/ET计入真实特征和推理时间。ET分类标签为online_success，五数值头为原始效用增量、删除、新增、移动和方法时延。校准使用验证网格20个正预算动作，分负载记录，不能据此重新拟合模型。推理按成功概率阈值过滤，再依预测效用/删除/新增/移动排序，概率只作最后并列裁决。

PUCT训练密度标准化统计仅来自4000默认训练任务，温度验证使用全部验证12情景×双负载，种子11；ALNS固定设置同样验证，用ALNS7.0框架。反应系数0.8对应旧权重0.2＋新段奖励0.8（包decay=0.2），每20次更新。修复中的最小增量定义为终端占用增量2p，接纳时刻等待作并列裁决；regret-2用前两个不同可行整数开始时刻差、唯一可行时刻记horizon；三算子均优先本次紧急任务并遵守累计接纳预算。搜索不使用精确答案，验证后的参数冻结供后续阶段使用。

本文件不是P3完成报告；只有全部标签、网格、规则、ET、搜索验证与审计完成后才可验收P3。不生成测试实例，不启动P4。
