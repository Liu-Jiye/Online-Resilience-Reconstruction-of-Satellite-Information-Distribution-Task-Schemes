# 后续贡献定位 v1：快速轻量局部修复与强搜索需求边界

用户于本会话明确确定后续贡献为：**“快速完成轻量局部修复，并明确何时需要更强搜索”。**

本文记录后续研究问题与结论范围，不改写原实验方案、已冻结协议、方法实现或历史结果；不授权启动下一实验阶段。阶段推进仍以用户指令为准。

## 研究问题与证据要求

1. 在规定的离散 ISL 模型中，直接插入、单项替换等轻量修复能否在统一端到端时间预算内，取得有用的服务、效用与计划稳定性结果？评价须保留全部适用事件与超时分母，分别报告计划可行、服务成功和按时成功。
2. 相对于验证择优固定参数、规则控制及方案要求的强搜索参照，轻量方法的质量、干扰和时延取舍是什么？自适应控制或轻量方法的优势均需实际比较，不能由机制简单或少数成功案例直接推断。
3. 哪些失败来自请求自身无物理机会、背景日历或冻结承诺，哪些来自候选资格、有限邻域、搜索算子或时间限制？须区分局部域不可行、启发式未找到解和超时；仅有适当精确证据时使用“不可行”或“最优”。
4. 更强搜索在什么条件下实际恢复服务或改善结果，代价是什么？已取得的精确离线参照用于分析可达差距，不能直接作为在线升级能力。

## 当前已有证据及其边界

- P0～P2 及补充是基于文档重新实现的 ISL 证据，不是原 HIST 的精确历史复现。
- P2-C 单项释放组 PALR 服务 50/50；两项与三项释放分别 0/25、0/25，而同域精确参照可服务。这支持现有插入／单项替换算子的能力边界，不支持“仅调 w/B 即可普遍解决复杂竞争”。这些受控模板比例不能外推为自然总体发生率。
- P2-C 邻域外阻塞组的 w5 与独立 w20 运行对比支持扩大邻域在该组的作用；它不是已经完成的自动升级策略，也不能把两次独立运行的预算合并忽略。
- 默认自然层继续保留；新增 N500/h0.8、4 热点星的中竞争层已通过训练／验证诊断并冻结。该层尚未运行修复方法，高竞争层未冻结。
- 原自然紧急请求中仍有大量无物理机会，须与机会条件探针、受控挑战分别报告。方法未接纳不自动意味着任务不可行。

## “何时需要更强搜索”的两种结论

**事后边界诊断**：以完整日志、独立诊断、受控机制和适当的精确参照，解释轻量方法为什么失败，以及更大邻域／更强搜索是否存在改进空间。可使用离线证据，但必须标明其事后性质；不能把固定参考计划的冲突数当作允许联合移动后的最少删除数。

**在线升级判断**：只使用决策时可获得的信息，并在训练／验证中预先确定触发规则。触发判定、特征计算、轻量阶段、后续搜索和最终校验全部共享同一端到端预算。需要实际评估触发率、额外服务收益、效用、干扰、时延分位数和超时，并与轻量单独运行、强搜索单独运行比较。

当前仅已具备部分事后边界证据，未完成在线触发规则或升级策略验证。不得使用事后精确答案决定在线是否升级，不得未经实验声称可以可靠识别所有需要强搜索的事件。未证实在线识别能力时，贡献表述应限于已经验证的边界诊断。

## 后续实验与写作约束

- 默认自然层、新增中竞争层、受控机制组分别统计；配对比较保持输入、约束与计时口径一致，相关变体按基础场景及卫星组处理相关性。
- 多项释放失败可作为有价值的能力边界如实呈现，无需为消除反例而修改既有算子。任何新算子或升级实现另定版本，保留原方法作参照；重要协议变更先与用户确认。
- 未获实验支持前，不宣称轻量方法普遍优于强搜索、接近全局最优、具备硬实时保证，或真实星间通信系统可靠性保证。
- 参数、规则或学习控制若未显示增益，如实报告并收缩贡献，不以自适应名称替代比较证据。
- 本定位不等于 P3 已启动。后续阶段按用户授权实施，完成后独立报告。
