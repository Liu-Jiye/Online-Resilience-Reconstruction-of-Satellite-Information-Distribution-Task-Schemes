# 实验数据与基线

历史 PALR 协议为 50 个仿真实例，每实例 100 个候选观测任务，规划时域 5400 秒。原生成器、具体种子与逐实例日志尚未恢复。当前 ISL 实验覆盖 6000 个基实例，训练、验证、测试为 4000、1000、1000。P4 默认负载对 1000 个测试基实例各派生 12 个事件。三类事件为取消、紧急插入和效用更新。规模和阶段入口见 [实验工作区](../experiment_runs/README.md)。

## 正式基线与计分

P4 运行 Minimal-Repair、Frozen-Greedy、Fixed-PALR、Validation-Best-Fixed、Rule-PALR、PUCT-ISL、ALNS-ISL 和 CP-SAT-50ms。各方法共享实例、参考计划、事件和 50 ms 在线预算。学习先验 PUCT、学习型局部修复和算子策略保留为历史对照。ExtraTrees 在验证阶段评估。P4 全后缀搜索与 P5 同邻域比较分别报告。[阶段报告](../experiment_runs/reports/p4/P4-20261117/P4_REPORT.md)

严格可行需通过独立计划校验。严格紧急服务还需纳入紧急任务，在线成功还需在时限内返回。完整调用时延计入状态提取、控制、修复、校验及返回开销。失败和超时保留在适用事件分母中，不适用事件单列。迟到或无严格可行输出的适用事件执行效用计零，按时可行输出的条件质量单报。[指标源码](../experiment_runs/src/isl/metrics.py)

P5 已执行窗口与接收端检查、B/w 扫描、固定/仅 B/仅 w/联合规则及离线网格比较。读取测试结果的网格参照用于事后诊断。P6 以基实例配对，轨道层先重采卫星组、再重采组内实例，报告 10000 次配对簇重采样的 95% 区间。[P5 报告](../experiment_runs/reports/p5/P5-20261118/P5_REPORT.md) · [P6 报告](../experiment_runs/reports/p6/P6-20261118/P6_REPORT.md)
