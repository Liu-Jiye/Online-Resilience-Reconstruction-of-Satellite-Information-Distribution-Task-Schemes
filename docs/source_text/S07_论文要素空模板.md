背景与场景

论文的研究背景，论文解决的是哪类场景，业务需求是什么



业务问题

业务层面的问题，围绕解决需求过程中存在的业务或场景里的问题，这里不是技术问题



研究思路

解决业务问题的思路，逻辑思路，即解决业务问题的思路或过程是什么。

技术/科学问题

在上述研究思路的实施过程中，遇到的技术/理论层面的问题是什么，即待突破的技术问题或关键科学问题

技术思路

解决上述技术问题或关键科学问题的思路，提出新技术/理论、发现新规律。新技术/理论，如何解决关键科学问题或技术问题。如何发现新规律，新规律的作用，即能够增强什么能力或提升什么效果。

创新点

与已有研究不一样的地方是什么，新的东西是什么。

实验数据

需要查询要投稿的会议已经录用的论文中实验数据集是使用的公开数据集还是使用仿真数据集还是采集真实数据集，还是都有？然后严格按照已经录用论文所使用的数据集类型，若多篇论文几乎都有公开数据集，你需要帮我全网检索适合此论文的公开数据集及链接。若多篇论文几乎都有仿真数据集，测需要给出数据集仿真方案，此方案务必保证仿真数据集与真实场景数据的贴近度。若多篇论文几乎都有真实采集数据集，那么请给出需要真实采集的数据集设计方案。

特别注意：实验应尽可能使用公开数据集，而且尽可能多个公开数据集，这样实验结果的说服力会更高。需要你帮我搜寻公开数据集。还需要判断公开数据集的字段是否满足论文的实验需求，若不满足，则可以基于真实数据集进行修改和合理生成相关数据，直到满足论文所需数据。

给出常用的评价指标，以及论文提出的新的评价指标
